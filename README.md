# UNINTA Metric

**Gestão e Performance de Campanhas**

Plataforma interna do Centro Universitário UNINTA para importar, normalizar e analisar relatórios de mídia, com foco em origem, eficiência, qualidade de dados e aprendizado entre campanhas.

## Stack

- React 19 + TypeScript
- TanStack Start / Router
- Vite 8
- Tailwind CSS 4
- Recharts
- XLSX + CSV
- Zod

## Desenvolvimento

```bash
npm install
npm run dev
```

A aplicação abre por padrão em `http://localhost:8080`.

## Build

```bash
npm run build
```

## Estado atual

Versão **0.3.2 — Clean Foundation**. A persistência do MVP continua local no navegador; a arquitetura de backend/CRM será incorporada em etapas posteriores.

## Produto

O UNINTA Metric transforma dados brutos de campanha em uma leitura auditável de performance. O Meta Ads permanece com importação manual de arquivos; integrações de CRM são previstas para evolução posterior.
